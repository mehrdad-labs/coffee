# Coffee for coffee lovers

جهت فان و گرفتن روحیه

بیلدشم که بلدید دیگه آسونه چه در ویندوز چه در لینوکس کافیه بنویسید:
```
go build .
```

بعد فایل اجرایی رو یجایی بذارید که سیستم عامل بشناسه!

برای ویندوز بندازید توی `windows` یا `system32`

و برای لینوکس بندازید توی `/bin`

به همین راحتی...

برای پروژه های فان بیشتر یه سر به کانال یوتوبم بزن:
https://www.youtube.com/@GeekTalk-ir
